# Project Configuration

This file maps project directories to Notion database IDs.

Replace the placeholder IDs below with your actual database IDs:

```bash
# Reccs Project
RECCS_DIR="/Users/johnasbury/reccs"
RECCS_IDEAS_DB="YOUR_RECCS_IDEAS_DATABASE_ID_HERE"
RECCS_TASKS_DB="YOUR_RECCS_TASKS_DATABASE_ID_HERE"

# Reachh Project
REACHH_DIR="/Users/johnasbury/Reachh"
REACHH_IDEAS_DB="YOUR_REACHH_IDEAS_DATABASE_ID_HERE"
REACHH_TASKS_DB="YOUR_REACHH_TASKS_DATABASE_ID_HERE"

# WordPress Project
WORDPRESS_DIR="/Users/johnasbury/Documents/Wordpress"
WORDPRESS_IDEAS_DB="YOUR_WORDPRESS_IDEAS_DATABASE_ID_HERE"
WORDPRESS_TASKS_DB="YOUR_WORDPRESS_TASKS_DATABASE_ID_HERE"

# Brand Engine Project
BRAND_ENGINE_DIR="/Users/johnasbury/ai_img"
BRAND_ENGINE_IDEAS_DB="YOUR_BRAND_ENGINE_IDEAS_DATABASE_ID_HERE"
BRAND_ENGINE_TASKS_DB="YOUR_BRAND_ENGINE_TASKS_DATABASE_ID_HERE"
```

## Alternative: Single Database with Project Property

If you use one "Ideas Inbox" database with a "Project" select/multi-select property:

```bash
UNIFIED_IDEAS_DB="YOUR_IDEAS_INBOX_DATABASE_ID_HERE"
UNIFIED_TASKS_DB="YOUR_TASKS_DATABASE_ID_HERE"
```
